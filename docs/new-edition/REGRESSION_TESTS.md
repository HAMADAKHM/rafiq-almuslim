# اختبارات منع التراجع

تُشغَّل قبل كل التزام مرحلة، وفي CI عند كل دفع.

## آلية
| الأمر | يغطي |
|---|---|
| `npx tsc -b` | الأنواع |
| `npx vitest run` | المواقيت والتوقيت الصيفي، والقبلة، وسلامة نص القرآن (`quran.integrity`)، ومنع المحارف العثمانية في الكود (`content.test`)، والأذكار، والختمة، والحفظ، والاشتراك والاستحقاق، والإعلانات، والثيمات، والودجت، والتلفاز (`tvRemote`، `v02`)، والرمضان، والاستوديو |
| `npx playwright test` (مع `VITE_PLUS_UNLOCK=0`) | النواة المجانية غير مقفلة، وبلس مقفل دون اشتراك، والإعلانات في الصفحات الأربع فقط، والثيمات، والبطاقات، والرفيق، والقارئ الجديد (النص مطابق للمصدر حرفيًا)، والتحكم بالتلفاز |
| `./gradlew testDebugUnitTest` (android-tv) | توقيع HMAC، وقبول روابط التحديث للنسخة الصحيحة فقط، ورد `/info` |

## اختبارات العزل الخاصة بالنسخة الجديدة
- [x] `RemoteCoreTest`:
  - التلفاز الجديد يرفض `RafiqAlMuslim-TV.apk` (الأصلي) ويقبل `RafiqAlMuslimTVNew.apk`.
  - `/info` يعيد `rafiq-tv-new`.
- [x] `v02.test`:
  - `pickTvRelease` يتجاهل إصدارات الملف الأصلي.
  - `pingTv` يرفض تلفازًا يعيد `rafiq-tv` (الأصلي) ويقبل `rafiq-tv-new`.
- [ ] **يدوي على جهاز:**
  - تثبيت الأصلي والجديد معًا: أيقونتان وبيانات منفصلة.
  - حذف الجديد لا يمس الأصلي.

## قائمة يدوية قبل أي إصدار
1. فتح القرآن وقراءة سورة، والعودة إلى آخر موضع.
2. ظهور المواقيت للمدينة، ورن الأذان في وقته (أو بزر التجربة).
3. جلسة أذكار بالعدّ، وتشغيل ذكر مسجّل.
4. التسبيح، والبطاقات، والمشاركة.
5. إقران التلفاز الجديد، وتغيير المشهد من الهاتف.
6. عدم مقاطعة HDMI.
7. تغيير الثيم، وإعادة تشغيل التطبيق مع بقاء الاختيار.
8. التصدير والاستيراد.
