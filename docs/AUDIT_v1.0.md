# تدقيق رفيق المسلم وتقرير الإصدار 1.0.0-beta.1

التاريخ: 20 أكتوبر 2026
- نقطة البدء: الفرع `feature/v0.9-pro`، والنسخة التجريبية beta-v0.9.0-build.12.
- فرع العمل: `feature/rafiq-1.0`.
- لم يُنشر أي إصدار رسمي. والفرع الرئيسي `main` باقٍ على 0.4.0.

## 1. نتيجة التدقيق قبل البدء

راجعتُ حالة 0.9.0 (التفاصيل في [AUDIT_v0.9.md](AUDIT_v0.9.md)):
- التقنيات كما هي: React 19 وTypeScript وVite وCapacitor 8، وIndexedDB بإصدار مخطط 1.
- لا تغيير في مخطط قاعدة البيانات في هذا الإصدار، ولا ترحيل ولا حذف لبيانات المستخدمين:
  - الإعدادات الجديدة لها قيم افتراضية تُدمج عند التحميل.
  - البيانات الجديدة (التصاميم، والمساجد المفضلة) مفاتيح جديدة في مخزن `kv`.
- لا مفاتيح API ولا أسرار في الشيفرة. لا خدمة جديدة تحتاج مفتاحًا.
- لم يُعَد كتابة التطبيق ولم يُحوَّل إلى إطار آخر. بقيت كل الميزات السابقة، وتحقق من ذلك 68 اختبارًا عبر المتصفح.

## 3. الاختبارات (تشغيل فعلي في 20 أكتوبر 2026)

| الفحص | النتيجة |
|---|---|
| TypeScript (`tsc -b`) | بلا أخطاء |
| Vitest | 180 اختبارًا ناجحًا في 26 ملفًا |
| Playwright (Chromium) | 68 اختبارًا ناجحًا |
| oxlint | بلا أخطاء (تحذيرات قديمة فقط) |
| بناء الويب (`npm run build`) | ناجح |
| بناء Android (APK) | يُبنى في GitHub Actions بعد الدفع؛ بيئة العمل بلا Android SDK. النتيجة تُذكر في الرد بعد انتهاء البناء |
| iOS | لا يمكن البناء هنا (يحتاج Mac وXcode) |

الاختبارات الجديدة تغطي:
- **الختمة:** تحويل الدقائق إلى صفحات، والجزء الحالي، والتأخر والتمديد.
- **الأحاديث:** صيغة التخريج، وظهورها في البحث.
- **الاستوديو:** بطاقة الحديث، والحفظ والفتح والحذف، وعدم حفظ النص أو صور المستخدم.
- **المساعد:** يعرض النص والمصدر، ولا يطلب أي اتصال خارجي، وينبّه في أسئلة الأحكام، وكل روابطه لأقسام موجودة.
- **المساجد:** الرادار، والمفضلة بعد إعادة التحميل، والبحث في مدينة.
- **مفتاح المتابعة:** لا يُسجَّل نشاط، والختمة تتقدم.
- **المقارنة بالتقويم الرسمي:** الفرق والتطبيق ورفض الفروق الكبيرة.
- **ودجت آية اليوم:** الآيات الطويلة لا تُقصّ.
- **رقم الإصدار:** متسق بين المنصات.

## 4. ما لم يُختبر على جهاز حقيقي

- ودجت «آية اليوم والورد»:
  - يعرض النص بخط النظام، لأن الودجت لا يستخدم خط المصحف المدمج. تلزم مراجعة علامات الرسم العثماني على الهاتف.
  - تغيّر اليوم يعتمد على التحديث الدوري للودجت (كل ساعة تقريبًا) وعلى فتح التطبيق.
- إضافة إلى ما سبق في 0.9:
  - الأذان والتطبيق مغلق.
  - البحث بالصوت.
  - الفيديو على الهاتف.
  - خادم المساجد الحي (محجوب عن بيئة العمل، واختُبر بخادم محاكى).

## 5. التكاليف

- **لا تكاليف تشغيل في هذا الإصدار.** كل الميزات الجديدة محلية.
- **OpenStreetMap/Overpass:** مجاني دون مفتاح، مع الالتزام بسياسة الاستخدام المعقول.
- **إن أردت لاحقًا مساعدًا بالذكاء الاصطناعي:**
  - تكلفة لكل سؤال لدى مزوّد النموذج.
  - خادم وسيط يحفظ المفتاح، فلا يوضع في التطبيق.
  - موافقة صريحة قبل إرسال أي سؤال.
  - قيود تمنع اختلاق آيات أو أحاديث: يُعرض النص من مصادر التطبيق فقط، ويقتصر النموذج على اختيار المراجع.
  - هذا قرار لك، ويتعارض مع وعد «مجاني بالكامل» إن صار باشتراك.

## 6. مشكلات معروفة

- المحتوى الشرعي (الأذكار والأحاديث وأرقامها والدروس) يحتاج مراجعة متخصص قبل النشر العام.
- رمز الإصدار على Android هو 91 لهذه النسخة التجريبية.
  - النسخ التجريبية ما زالت موقّعة بمفتاح تجريبي متغير، فيلزم حذف النسخة السابقة قبل التثبيت.
- مطابقة آيات المساعد بالكلمات لا بالمعنى. يوضح التطبيق ذلك، ويضع رابط التفسير بجانب كل آية.
- ودجت iOS والمزامنة غير منفذين.
