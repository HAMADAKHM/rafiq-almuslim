## ب. التعديلات المنفذة

### ميزات جديدة
1. **تطبيقا Android وiOS (Capacitor 8)**: مشروعا `android/` و`ios/` مولّدان ومهيآن (الاسم العربي، الأيقونات، أذونات الموقع التقريبي والإشعارات، تشغيل الصوت في الخلفية على iOS، أيقونة إشعار أحادية اللون).
2. **إشعارات محلية مجدولة حقيقية على الهاتف**: جدولة 7 أيام مقدمًا (حد iOS 64 إشعارًا)، إعادة الجدولة عند فتح التطبيق وعند تغيير المدينة أو الإعدادات، وبعد إعادة تشغيل الجهاز (Android عبر الإضافة)، وفتح الصفحة المناسبة عند الضغط على الإشعار.
3. **صفحة «إعدادات التذكير»**: لكل صلاة على حدة، عند الأذان و/أو قبله، أذكار الصباح والمساء والنوم، آية اليوم، ذكر اليوم، الورد، الحفظ، المناسبات، ملخص يومي، **وضع تقليل الإشعارات**، **فترة هدوء**، ومعاينة للتذكيرات القادمة. رسائل متنوعة بلا لوم وبلا نسبة فضائل.
4. **وضع المصحف (صفحات مصحف المدينة 604)** مع التنقل بالأزرار أو الأسهم أو السحب.
5. **قائمة خيارات الآية** (عند الضغط على الآية): التلاوة من هنا، تكرار الآية بعدد محدد، التفسير، المفضلة، النسخ، المشاركة، **بطاقة صورة**، ملاحظة، موضعها في المصحف، قرأت حتى هنا، **علامة مرجعية مسماة**.
6. **خلفيات القراءة** (عاجي، أبيض، ورقي دافئ، ليلي) وتذكّر الوضع والخط والخلفية، وضع تركيز بملء الشاشة.
7. **ترجمة إنجليزية معتمدة** (Saheeh International) اختيارية تحت الآيات، مضمّنة وتعمل دون إنترنت.
8. **خطط الختمة**: بمدة (7/15/30/60/مخصصة) أو بعدد صفحات، حساب الورد تلقائيًا حسب المتبقي، تسجيل يدوي («قرأت ورد اليوم» أو «حتى الصفحة»)، إيقاف/استئناف، حذف وإعادة ضبط بتأكيد، سجل الختمات. **يُرحَّل الورد القديم تلقائيًا دون فقد موضعه أو عدد ختماته.**
9. **المسبحة**: أذكار جاهزة أو ذكر خاص، هدف عددي، اهتزاز وصوت اختياريان، سجل يومي اختياري، حفظ العدد، تصفير بتأكيد، دعم مفتاح المسافة وقارئ الشاشة.
10. **التقويم الإسلامي**: شهر ميلادي بما يقابله هجريًا، المناسبات (رأس السنة، عاشوراء، رمضان، العيدان، عرفة، التشريق، الأيام البيض، الاثنين والخميس) مع مصادرها، وتنبيه صريح باختلاف الرؤية.
11. **آية اليوم وذكر اليوم**: من مراجع محددة، النص من المصحف كاملًا، مع الاستماع والتفسير والمشاركة كصورة.
12. **بطاقات المشاركة**: آية أو ذكر، ثلاثة مظاهر، معاينة قبل المشاركة، واجهة المشاركة الأصلية، دون زخارف فوق النص ودون علامة مائية مزعجة.
13. **رئيسية جديدة قابلة للتخصيص**: تحية بحسب الوقت، الصلاة القادمة، أكمل قراءتك، ورد القرآن ونسبته، أذكار الوقت الحالي، آية اليوم، وصول سريع (المسبحة، الأدعية، القبلة، التقويم)، إنجاز اليوم؛ مع إخفاء البطاقات وترتيبها (بطاقة الإهداء يمكن نقلها ولا يمكن إخفاؤها).
14. **الأذكار**: حفظ العدادات لكل يوم، زر «التالي»، تكبير/تصغير النص، مشاركة كبطاقة، تأكيد لمس عند اكتمال العدد.
15. **القبلة**: تحذير عند ضعف دقة المستشعر أو عدم إطلاقه.
16. **المفضلة للآيات** في فهرس القرآن.
17. **بناء APK آليًا** عبر GitHub Actions (`.github/workflows/android.yml`).

**ما أُصلح أثناء العمل:** حفظ عدادات الأذكار عند الضغط السريع، حفظ المسبحة عند مغادرة الصفحة، عناوين أيام التقويم الملتبسة (الأحد/الأربعاء)، اختبار كان يعتمد على ساعة الجهاز.

**ما لم يُختبر ولماذا:**
- **بناء Android**: محاولة `./gradlew assembleDebug` فشلت لأن سياسة الشبكة في بيئة البناء تحجب `dl.google.com` (مستودع Google لإضافات Gradle وحزمة Android SDK). سيعمل البناء في GitHub Actions أو على جهازك مع Android Studio.
- **بناء iOS**: يتطلب جهاز Mac مع Xcode — غير متاح في البيئة.
- **الإشعارات المجدولة والاهتزاز والمشاركة الأصلية والموقع الأصلي**: الشيفرة مكتوبة على واجهات Capacitor الرسمية، ومنطق الجدولة مختبر بالوحدات، لكن السلوك الفعلي على الهاتف (بعد إعادة التشغيل، توفير الطاقة، تغيير المنطقة الزمنية) **يحتاج اختبارًا على جهاز حقيقي**.
- **التلاوات من الخادم الحقيقي**: ما زال everyayah.com محجوبًا في بيئة البناء.
- **الودجت**: لم يُنفَّذ (انظر هـ).

## د. التشغيل والبناء

```bash
npm install
npm run dev            # نسخة الويب للتطوير
npm test               # اختبارات الوحدات
npm run test:e2e       # اختبارات المتصفح (مرة واحدة: npx playwright install chromium)
npm run build:standalone   # ملف HTML واحد يعمل بالنقر المزدوج
```

### Android
1. ثبّت Android Studio (يتضمن Android SDK وJava).
2. `npm run cap:sync` ثم `npm run android:open` → في Android Studio: Run على هاتف أو محاكٍ.
3. أو مباشرة: `npm run android:apk` → الملف في `android/app/build/outputs/apk/debug/app-debug.apk`.
4. أو بلا أي أدوات: ارفع المشروع إلى GitHub فيبني الـ workflow ملف APK قابلًا للتنزيل من تبويب Actions.
5. للنشر في Google Play: أنشئ مفتاح توقيع (keystore) **واحفظه خارج المستودع**، وأضف إعداد `signingConfigs` أو استخدم Android Studio → Generate Signed Bundle.

### iPhone
1. على جهاز Mac مع Xcode 16+: `npm run cap:sync` ثم `npm run ios:open`.
2. اختر فريق التطوير (Apple Developer) في Signing & Capabilities، ثم Run على جهاز أو محاكٍ.
3. مضاف مسبقًا: نصوص أذونات الموقع والحركة بالعربية، وتشغيل الصوت في الخلفية.

لا توجد مفاتيح API أو أسرار مطلوبة لأي ميزة حالية.

## هـ. ما يحتاج استكمالًا

| الميزة | الحالة | ما يلزم |
|---|---|---|
| ودجت الشاشة الرئيسية | غير منفذ | يتطلب شيفرة أصلية (Kotlin + Glance لـ Android، وSwiftUI WidgetKit لـ iOS) مع مشاركة البيانات عبر App Group/SharedPreferences، واختبارًا على أجهزة. لم أنشئ ودجت شكليًا لا يتحدث |
| تمييز الكلمة أثناء التلاوة | غير منفذ | التمييز الحالي على مستوى الآية (دقيق لأن لكل آية ملفًا مستقلًا)؛ التمييز الأدق يحتاج بيانات توقيت مرخّصة |
| وضع المصحف مطابق للسطور المطبوعة | جزئي | حدود الصفحات صحيحة، لكن توزيع الأسطر يتبع الشاشة؛ المطابقة تحتاج خطوط مجمع الملك فهد للصفحات (QCF) وبيانات الأسطر وترخيصها |
| تشغيل الصوت في الخلفية على Android مع قفل الشاشة | غير مضمون | WebView قد يوقف الصوت؛ الحل إضافة مشغل أصلي (Media3 + خدمة أمامية) |
| تنزيل التلاوات دون اتصال على الهاتف | منفذ للويب | يحتاج تحققًا من شروط EveryAyah واختبارًا على الجهاز |
| قراءة صوتية للأذكار | غير منفذ | لا يوجد تسجيل صحيح المصدر ومرخّص متاح |
| تقييم النطق | غير منفذ عمدًا | لا تقنية موثوقة مختبرة |
| المراجعة الشرعية | مطلوبة | الأذكار والدروس وأحكام التقويم تحتاج مراجعة متخصص قبل النشر |

## و. الأولويات التالية (بحسب الحالة الفعلية)
1. بناء APK عبر GitHub Actions أو Android Studio، وتجربة الإشعارات على جهاز حقيقي (إعادة التشغيل، توفير الطاقة، تغيير المنطقة الزمنية).

5. نشر تجريبي مغلق (Google Play Internal Testing وTestFlight).

**الاختبارات:** 103 اختبار وحدات و34 اختبار متصفح — كلها ناجحة (أُضيفت اختبارات: إعدادات القراءة تُحفظ بعد إعادة التحميل، وضع التركيز والتنقل، صفحة معلومات السورة، وحُدّثت اختبارات القارئ والمصحف).
