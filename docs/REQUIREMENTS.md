# وثيقة المتطلبات — رفيق المسلم (الإصدار 0.1.0، نسخة الكمبيوتر)

## الرسالة

تطبيق إسلامي مجاني بالكامل، صدقة جارية عن روح المرحوم **قصي بديع خلفه — «أبو محمد»**، يخدم المسلمين الملتزمين وغير الملتزمين في قراءة القرآن وحفظه، والمحافظة على الصلاة والأذكار، والتعلم، والاستماع، وبناء عادات إيمانية يومية.

## متطلبات غير وظيفية (إلزامية)

| # | المتطلب | التحقق |
|---|---|---|
| N1 | مجاني بالكامل: لا إعلانات، لا اشتراكات، لا مشتريات، لا طلبات تبرع، لا ميزات مقفلة | اختبار e2e يفحص النصوص، واختبار وحدة يمنع مكتبات الإعلانات والتحليلات والمدفوعات |
| N2 | لا حساب مطلوب، وكل البيانات على الجهاز | تصميم: IndexedDB فقط |
| N3 | واجهة عربية كاملة RTL، متجاوبة، وضع ليلي | e2e (dir/lang، شاشة 390px دون تمرير أفقي، الوضع الليلي) |
| N4 | إمكانية الوصول ولوحة المفاتيح | رابط تخطٍّ، تسميات ARIA، تركيز مرئي، اختبار e2e |
| N5 | العمل دون إنترنت للوظائف الأساسية | Service Worker + e2e دون اتصال |
| N6 | لا نصوص قرآنية مولدة أو مكتوبة يدويًا | اختبار يمنع حروف الرسم العثماني في الشيفرة + سلامة المصحف |
| N7 | لا أحاديث أو فضائل مختلقة | تخريج لكل عنصر + اختبار + مراجعة شرعية مطلوبة |
| N8 | لا مفاتيح API سرية في الواجهة | لا توجد أي مفاتيح؛ كل المصادر عامة |
| N9 | رسالة الوفاء ثابتة في كل الإصدارات | `src/content/dedication.ts` + اختبار يمنع تغيير النص والاسم والكنية |
| N10 | بنية قابلة للنقل إلى Android/iOS | طبقة `platform` و`sync` منفصلة؛ Capacitor مخطط |
