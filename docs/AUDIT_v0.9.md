# تدقيق رفيق المسلم قبل الإصدار 0.9.0

التاريخ: 20 أكتوبر 2026 • نقطة البدء: الفرع `feature/v0.8-studio-video` (النسخة التجريبية beta-v0.8.0-build.10) • فرع العمل: `feature/v0.9-pro`

## 1. التقنيات المستخدمة فعلًا

| الطبقة | التقنية والإصدار |
|---|---|
| الواجهة | React 19.3، TypeScript 7.0، Vite 8.3، react-router |
| التخزين المحلي | IndexedDB عبر `idb` 8 (المخازن: kv، bookmarks، notes، memo، memoLog، readLog، adhkarLog، favorites، listenLog؛ `DB_VERSION = 1`) |
| العمل دون اتصال | vite-plugin-pwa (Workbox) |
| الجوال | Capacitor 8.5.3، وإضافات: local-notifications، geolocation، filesystem، share، haptics، app، والتعرف على الكلام `@capacitor-community/speech-recognition` 7.0.1 |
| الشيفرة الأصلية | Android: ودجت المواقيت (`PrayerWidgetProvider`)، وجسر الودجت، وصوت الأذان من الجهاز (`AdhanSoundPlugin`) |
| المحتوى | المصحف: `quran-json` 3.1.2 (QuranEnc/مجمع الملك فهد، CC BY-SA 4.0) مع تحقق آلي وبصمة SHA-256؛ البيانات الوصفية: `quran-meta`؛ المواقيت: `adhan` 4.4.6؛ المدن: GeoNames؛ التفسير: `tafsir_api` عند الطلب؛ التلاوات: EveryAyah وIslamic Network |
| الاختبار | Vitest (140 اختبارًا) وPlaywright على Chromium (55 اختبارًا)، وoxlint |
| البناء | GitHub Actions: بناء APK تجريبي عند كل دفع |

## 2. حالة الوظائف

**مكتملة ومختبرة آليًا:**
- المصحف (عرض متتابع، وصفحات، وتركيز) وفهارس السور والأجزاء والأحزاب والصفحات.
- حفظ آخر موضع، والعلامات والملاحظات والمفضلة.
- الختمة، والحفظ بالمراجعة المتباعدة (SM-2).
- المواقيت بـ12 طريقة حساب مع تعديل الدقائق، والقبلة.
- الأذكار (جلسة وعدّاد وانتقال تلقائي)، والأذكار الشخصية، والمسبحة، والتقويم الهجري.
- التذكيرات، وصوت الأذان داخل التطبيق.
- استوديو الصور والفيديو، والبحث المكتوب.
- السمات الفاتحة والداكنة والذهبية، والعمل دون اتصال، والنسخ الاحتياطي.

**تُبنى بنجاح لكنها غير مختبرة على جهاز حقيقي:**
- الأذان والتطبيق مغلق على Android (قناة إشعار بصوت الأذان).
- ودجت Android.
- البحث بالصوت على الهاتف: أفاد المستخدم بأنه «غير فعال» في 0.7، وعُدّل في 0.8 دون تأكيد من جهاز حقيقي.
- إنشاء الفيديو على الهاتف.
- مقطع الـ30 ثانية لإشعارات iOS.

**غير منفذة:**
- ودجت iOS (يحتاج امتدادًا أصليًا بـXcode).
- دليل المساجد.
- مزامنة البيانات بين الأجهزة.
- أصوات مؤذنين مدمجة (لا تسجيلات معروفة المصدر بعد).
- أسماء الله الحسنى، ومجموعة أحاديث مستقلة، والسيرة (لا مصدر موثّق متاح).

## 3. أخطاء ومخاطر مؤكدة

1. **تضارب أرقام الإصدار:**
   - `main` عند 0.4.0، والرابط الثابت `releases/latest` يعطي 0.4.0، بينما آخر نسخة تجريبية 0.8.0.
   - مشروع iOS على `MARKETING_VERSION = 1.0` و`CURRENT_PROJECT_VERSION = 1`.
2. **سباق في تحميل الإعدادات** (أُصلح في 0.8): أي تغيير قبل اكتمال التحميل كان يكتب الإعدادات الافتراضية فوق المحفوظة.
3. **ثغرات `npm audit`:**
   - ثلاث ثغرات «متوسطة»، كلها في أدوات التطوير فقط (`@capacitor/cli` ← `xcode` ← `uuid`) ولا تدخل في التطبيق.
   - الإصلاح المقترح تراجع كاسر للإصدار، فلم يُطبق.
   - `npm audit --omit=dev` = 0 ثغرات.
4. **الحزمة الرئيسية للواجهة 676 كيلوبايت في ملف واحد:** يبطئ أول فتح على الأجهزة الضعيفة.
5. **نشر الملفات دون موافقة:** يرفع البناء التلقائي نسخة تجريبية علنية مع كل دفع إلى فروع `feature/`، وهذا يخالف شرط «لا تنشر ملفات عامة دون موافقة».
6. **مستندات ناقصة:** لا يوجد `CHANGELOG.md` ولا ملف ترخيص للمشروع. اختيار ترخيص الشيفرة قرار صاحب المشروع.
7. **سياسة الخصوصية قديمة:** لا تذكر الميكروفون والتعرف على الكلام وملفات الأذان والفيديو المستوردة.

## 4. تجربة المستخدم

- **ألوان الهوية:** تختلف قليلًا عن اللوحة المطلوبة (#073B32، #237B6D، #C6A15B، #F5F0E6، #26352F).
- **تكرار الآية:** المشغل يكرر الآية بلا فاصل زمني بين التكرارات، والفاصل مهم للحفظ.
- **الرئيسية:**
  - لا يوجد ملخص أسبوعي.
  - الاختصارات الافتراضية لا تشمل الختمة.
- **الختمة:** لا يظهر هدف الأسبوع.

## 5. الأداء والأمان والخصوصية

- **الأذونات الحالية:**
  - الإنترنت.
  - الموقع التقريبي: يُطلب فقط عند ضغط «موقعي الحالي».
  - الإشعارات والتنبيه الدقيق.
  - الميكروفون: يُطلب فقط عند البحث بالصوت.
  - الأذونات كلها ضرورية للميزات الموجودة، ولا يُطلب أي إذن عند الفتح.
- **الأسرار:** لا توجد مفاتيح أو أسرار في المستودع (فُحص آليًا)، ولا يحتاج التطبيق أي مفتاح.
- **التتبع:** لا تتبع ولا تحليلات ولا إعلانات.

## 6. خطة 0.9.0 حسب الأولوية

1. **الاستقرار والبيانات:**
   - اختبارات المواقيت عند تغير التوقيت الصيفي والمنطقة الزمنية.
   - إيقاف النشر التلقائي للنسخ التجريبية إلا بطلب صريح.
   - توحيد أرقام الإصدار في كل الملفات (ومنها iOS).
2. **الأداء:** تقسيم الحزمة وتحميل الصفحات الثقيلة عند الحاجة.
3. **الهوية:** اعتماد اللوحة المطلوبة مع التحقق من التباين (WCAG AA).
4. **القرآن:**
   - فاصل زمني قابل للضبط بين تكرارات الآية.
   - هدف أسبوعي للختمة.
5. **الرئيسية:** ملخص أسبوعي، واختصارات القبلة والمسبحة والختمة.
6. **دليل المساجد:**
   - مصدر البيانات: OpenStreetMap عبر Overpass API، وهو مجاني ومفتوح (ODbL) وبلا مفتاح.
   - الموقع يُطلب فقط عند الضغط.
   - المسافة والاتجاه والفتح في تطبيق الخرائط.
   - لا ادعاء بأوقات الفتح.
7. **المستندات:** CHANGELOG، وREADME، وسياسة الخصوصية، و`.env.example`، وقائمة متطلبات الإصدار العام.
8. **المزامنة:** لا تُضاف في 0.9، لأنها تحتاج خادمًا وحسابات. البديل الحالي هو التصدير والاستيراد اليدوي. التفاصيل في `CHANGELOG.md`.
