# التكاليف والاستضافة

التطبيق مجاني للمستخدم بالكامل. هذه الوثيقة توضح التكاليف التقنية المحتملة على صاحب المشروع، واختيارات تبقيها عند الصفر أو قريبة منه.
**لا يجوز إضافة إعلانات أو اشتراكات أو نظام تجاري لتغطيتها.**

## الإصدار الحالي (الويب)

| البند | الحل المقترح | التكلفة المتوقعة |
|---|---|---|
| استضافة التطبيق | ملفات ثابتة (مجلد `dist` ≈ 3.5 م.ب) على Cloudflare Pages أو GitHub Pages أو Netlify | مجانية |
| اسم نطاق (اختياري) | مثل `rafiq-almuslim.org` | نحو 10–15 دولارًا سنويًا (اختياري تمامًا؛ يمكن استخدام النطاق المجاني للاستضافة) |
| نص المصحف والأذكار والمدن | مضمّنة في التطبيق | صفر |
| مواقيت الصلاة والقبلة | تُحسب على جهاز المستخدم | صفر — لا خادم |
| التفسير | ملفات ثابتة مفتوحة عبر jsDelivr/GitHub | صفر حاليًا؛ يُنصح مستقبلًا باستضافتها ذاتيًا على الاستضافة المجانية نفسها بعد التحقق من التراخيص |
| التلاوات | بث من EveryAyah | صفر على صاحب المشروع؛ الاعتماد على خدمة خارجية تطوعية |
| قاعدة بيانات/خادم | لا يوجد — IndexedDB على جهاز المستخدم | صفر |

## الإصدارات القادمة

| البند | التكلفة |
|---|---|
| حساب Google Play Developer | رسوم تسجيل لمرة واحدة (نحو 25 دولارًا) |
| حساب Apple Developer Program | اشتراك سنوي (نحو 99 دولارًا)؛ تتيح Apple إعفاء الرسوم لبعض المنظمات غير الربحية المؤهلة |
| الإشعارات المحلية للصلاة | تُجدول على الجهاز — صفر (لا حاجة لخادم إشعارات) |
| المزامنة السحابية (اختيارية) | يمكن البدء بحلول مجانية: تصدير/استيراد ملف (موجود)، أو مزامنة عبر حساب المستخدم الشخصي (Google Drive/iCloud)؛ أو خادم صغير بخطة مجانية. يجب أن تبقى اختيارية. |
| استضافة التلاوات ذاتيًا (إن لزم) | الملفات كبيرة (عشرات الغيغابايت للقارئ الواحد)؛ يُفضَّل البث من مصادر تطوعية موثوقة بإذنها بدل الاستضافة الذاتية |

## مبادئ الاستدامة

- لا خوادم ولا قواعد بيانات مركزية في النسخة الأولى.
- كل ما يمكن حسابه على الجهاز يُحسب عليه.
- المحتوى الثابت يُضمَّن في التطبيق ليعمل دون إنترنت ويقلل الطلبات.
