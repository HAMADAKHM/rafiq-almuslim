# رفيق المسلم | Islamic Companion

> **صدقة جارية عن روح المرحوم قصي بديع خلفه — «أبو محمد»**، رحمه الله رحمةً واسعة، وغفر له وأسكنه فسيح جناته.
> نسأل الله أن يجعل هذا العمل خالصًا لوجهه الكريم، وأن ينفع به المسلمين، وأن يتقبله بفضله وكرمه.

تطبيق إسلامي **مجاني بالكامل**: بلا إعلانات، ولا اشتراكات، ولا مشتريات داخل التطبيق، ولا طلبات تبرع، ولا يشترط إنشاء حساب.
بيانات المستخدم كلها محفوظة على جهازه فقط.

## أسهل طريقة: بدون تثبيت أي شيء

افتح الملف `RafiqAlMuslim.html` بالنقر المزدوج، فيعمل التطبيق في المتصفح مباشرة دون Node.js ودون إنترنت.
لإنشاء هذا الملف من الشيفرة: `npm run build:standalone` (يظهر في `dist-standalone/index.html`).
في هذه النسخة لا تعمل التنبيهات في الخلفية ولا تثبيت التطبيق كـ PWA، وبقية الوظائف تعمل.

## التثبيت والتشغيل (Windows / macOS / Linux)

افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع:

```bash
# 1) تثبيت المكتبات (مرة واحدة)
npm install

# 2) تشغيل نسخة التطوير
npm run dev
```

ثم افتح الرابط الذي يظهر (عادة `http://localhost:5173`) في المتصفح.
**لإيقاف التشغيل:** اضغط `Ctrl + C` في نافذة الأوامر.

### نسخة الإنتاج (مع العمل دون إنترنت)

```bash
npm run build      # يبني نسخة الإنتاج في مجلد dist
npm run preview    # يشغّلها على http://localhost:4173
```

العمل دون إنترنت (عامل الخدمة / Service Worker) يعمل في نسخة الإنتاج فقط. بعد أول فتح، يمكنك فصل الإنترنت وإعادة فتح التطبيق.
لتثبيته كتطبيق على الكمبيوتر: في Chrome/Edge اضغط أيقونة «تثبيت» في شريط العنوان.

لنشره على الإنترنت مجانًا: ارفع محتوى مجلد `dist` إلى أي استضافة ملفات ثابتة مجانية (Cloudflare Pages أو GitHub Pages أو Netlify)، مع توجيه كل المسارات إلى `index.html`. التفاصيل في [docs/COSTS.md](docs/COSTS.md).

### تطبيقا Android وiPhone

```bash
npm run cap:sync      # يبني نسخة الويب وينسخها إلى مشروعي android/ و ios/
npm run android:open  # يفتح المشروع في Android Studio (ثم Run)
npm run android:apk   # يبني ملف APK تجريبيًا (يحتاج Android Studio/SDK)
npm run ios:open      # على Mac مع Xcode فقط
```

أو دون أي أدوات: كل دفع إلى GitHub يبني ملف APK تجريبيًا يمكن تنزيله من تبويب Actions (`.github/workflows/android.yml`).
- **الفرع الرئيسي `main`:** ينشر أيضًا إصدارًا برابط ثابت.
- **فروع `feature/`:** لا تنشر شيئًا علنيًا إلا بتشغيل يدوي (Run workflow) مع اختيار «publish_beta».

**iPhone:** على جهاز Mac فيه Xcode 16 أو أحدث:
1. `npm ci && npm run cap:sync`.
2. `npm run ios:open`.
3. في Xcode: اختر فريق التوقيع (Signing & Capabilities) ثم Run.

لا يمكن بناء نسخة iPhone على Windows أو Linux.

| الختمة والحفظ | خطط بمدة أو بعدد صفحات أو بالوقت المتاح يوميًا، والجزء الحالي، وتمديد الموعد عند التأخر، وهدف يومي وأسبوعي، والحفظ بالمراجعة المتباعدة، وتكرار الآية بعدد وفاصل قابلين للضبط |

| المساعد الإسلامي | بحث محلي في المصحف والأحاديث والأذكار يعرض النصوص بمصادرها ورابط التفسير، بلا توليد ولا فتوى ولا إرسال للسؤال |

| أخرى | التقويم الهجري والمناسبات، والسمات الفاتحة والداكنة والأسود والذهبي، وودجت المواقيت وودجت «آية اليوم والورد» (Android)، ومفتاح «متابعة رحلتي الإيمانية»، والعمل دون اتصال، والنسخ الاحتياطي والاستعادة |

### ما لم يُختبر على جهاز حقيقي بعد

هذه الميزات تُبنى بنجاح، ولم تُجرَّب على هاتف حقيقي:
- الأذان والتطبيق مغلق.
- ودجت Android (المواقيت، وآية اليوم والورد).
- البحث بالصوت على الهاتف.
- إنشاء الفيديو على الهاتف.
- الاستعلام الحي من خادم المساجد (بيئة العمل تحجبه؛ اختُبر بخادم محاكى).

التفاصيل في [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).

### غير المنفذ

- ودجت iPhone.
- مزامنة البيانات بين الأجهزة (النسخ الاحتياطي اليدوي متاح).
- أصوات مؤذنين مدمجة: تنتظر تسجيلات معروفة المصدر، وتُضاف بـ `scripts/add-adhan.mjs`.
- أسماء الله الحسنى والسيرة: لا مصدر موثّق متاح بعد. (مكتبة الأحاديث أُضيفت في 1.0 بمختارات من الصحيحين.)
- المساعد بالذكاء الاصطناعي، وتقييم التلاوة بالصوت: دراسة فقط (انظر قائمة الإصدار).
- **المراجعة الشرعية:** الأذكار والأحاديث والدروس تحتاج مراجعة متخصص قبل النشر العام.

## الاختبارات

نتائج آخر تشغيل فعلي مذكورة في [CHANGELOG.md](CHANGELOG.md) لكل إصدار. تغطي الاختبارات:
- **المصحف:** العدد والترتيب والبصمة.
- **المواقيت:** مقارنة بتنفيذ فلكي مستقل، والتوقيت الصيفي (ومنه الفلسطيني)، وجهاز بمنطقة زمنية مختلفة عن المدينة.
- **القبلة.**
- **التخزين والترحيل.**
- **المحتوى الشرعي:** التخريج، ومنع النص القرآني المكتوب يدويًا، وثبات نص الإهداء.
- **الأقسام:** التنقل والأذكار والأذان والاستوديو والمساجد والعمل دون اتصال.

```bash
npm test                                   # Vitest
npx tsc --noEmit -p tsconfig.app.json      # فحص الأنواع
npm run lint                               # oxlint
npm run test:e2e                           # Playwright (Chromium)
```

## بنية المشروع

```
src/
├── app/          # التطبيق، المسارات (الصفحات الثانوية تُحمَّل عند الحاجة)، التخطيط، شريط التنقل، شاشة البداية
├── features/     # صفحة لكل قسم: home, quran, memorize, listen, learn, prayer, qibla, mosques, adhkar, tasbih, calendar, reminders, wird, studio, …
├── components/   # مكونات مشتركة: الرسوم الأصلية (Art)، البطاقات، المشغل، البحث بالصوت، الأذان داخل التطبيق
├── services/     # المنطق: القرآن، المواقيت، القبلة، المراجعة، الصوت، الأذان، الاستوديو، المساجد، الودجت
├── content/      # المحتوى الموثق: الأذكار، الأدعية، الدروس، الإهداء، القراء، أصوات الأذان
├── platform/     # قدرات الجهاز: الموقع، الإشعارات، المشاركة، التعرف على الكلام، الودجت
├── db/ state/ i18n/ styles/
android/app/src/main/java/org/rafiqalmuslim/app/   # ودجت المواقيت وصوت الأذان من الجهاز
e2e/ docs/ scripts/
```
