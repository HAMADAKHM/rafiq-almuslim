# رفيق المسلم | Islamic Companion

> **صدقة جارية عن روح المرحوم قصي بديع خلفه — «أبو محمد»**، رحمه الله رحمةً واسعة، وغفر له وأسكنه فسيح جناته.
> نسأل الله أن يجعل هذا العمل خالصًا لوجهه الكريم، وأن ينفع به المسلمين، وأن يتقبله بفضله وكرمه.

تطبيق إسلامي **مجاني بالكامل**: بلا إعلانات، ولا اشتراكات، ولا مشتريات داخل التطبيق، ولا طلبات تبرع، ولا يشترط إنشاء حساب.
بيانات المستخدم كلها محفوظة على جهازه فقط.

**الإصدار الحالي 0.2.0**: أُضيف تطبيقا Android وiPhone (Capacitor) مع إشعارات مجدولة، ووضع المصحف، وقائمة خيارات الآية، والختمات، والمسبحة، والتقويم الإسلامي، وآية اليوم، وبطاقات المشاركة، وإعدادات التذكير، ورئيسية قابلة للتخصيص. التفاصيل الكاملة ونتائج الاختبارات في [تقرير التسليم 0.2](docs/REPORT_v0.2.md).

كان الإصدار الأول (0.1.0) نسخة الكمبيوتر (تطبيق ويب يعمل في المتصفح، ويمكن تثبيته كتطبيق PWA ويعمل دون إنترنت).
نسختا Android ثم iPhone مخطط لهما على البنية نفسها (انظر [خطة الهاتف](docs/MOBILE_PLAN.md)).

لا تحتاج إلى هاتف لتجربة هذه النسخة.

## أسهل طريقة: بدون تثبيت أي شيء

افتح الملف `RafiqAlMuslim.html` بالنقر المزدوج، فيعمل التطبيق في المتصفح مباشرة دون Node.js ودون إنترنت.
لإنشاء هذا الملف من الشيفرة: `npm run build:standalone` (يظهر في `dist-standalone/index.html`).
في هذه النسخة لا تعمل التنبيهات في الخلفية ولا تثبيت التطبيق كـ PWA، وبقية الوظائف تعمل.

## التثبيت والتشغيل (Windows / macOS / Linux)

افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع:

```bash
# 1) تثبيت المكتبات (مرة واحدة)
npm install

# 2) تشغيل نسخة التطوير
npm run dev
```

ثم افتح الرابط الذي يظهر (عادة `http://localhost:5173`) في المتصفح.
**لإيقاف التشغيل:** اضغط `Ctrl + C` في نافذة الأوامر.

### نسخة الإنتاج (مع العمل دون إنترنت)

```bash
npm run build      # يبني نسخة الإنتاج في مجلد dist
npm run preview    # يشغّلها على http://localhost:4173
```

العمل دون إنترنت (عامل الخدمة / Service Worker) يعمل في نسخة الإنتاج فقط. بعد أول فتح، يمكنك فصل الإنترنت وإعادة فتح التطبيق.
لتثبيته كتطبيق على الكمبيوتر: في Chrome/Edge اضغط أيقونة «تثبيت» في شريط العنوان.

لنشره على الإنترنت مجانًا: ارفع محتوى مجلد `dist` إلى أي استضافة ملفات ثابتة مجانية (Cloudflare Pages أو GitHub Pages أو Netlify)، مع توجيه كل المسارات إلى `index.html`. التفاصيل في [docs/COSTS.md](docs/COSTS.md).

### تطبيقا Android وiPhone

```bash
npm run cap:sync      # يبني نسخة الويب وينسخها إلى مشروعي android/ و ios/
npm run android:open  # يفتح المشروع في Android Studio (ثم Run)
npm run android:apk   # يبني ملف APK تجريبيًا (يحتاج Android Studio/SDK)
npm run ios:open      # على Mac مع Xcode فقط
```

أو دون أي أدوات: ارفع المشروع إلى GitHub، فيبني ملف `.github/workflows/android.yml` ملف APK يمكن تنزيله من تبويب Actions. التفاصيل في [تقرير 0.2](docs/REPORT_v0.2.md#د-التشغيل-والبناء).

### الأوامر المتاحة

| الأمر | الوظيفة |

| `npm run dev` | تشغيل نسخة التطوير |
| `npm run build` | فحص الأنواع وبناء نسخة الإنتاج |

| `npm test` | اختبارات الوحدات (Vitest) |

## الوظائف

### المكتملة والمختبرة في هذا الإصدار

- **الرئيسية:** التاريخ الميلادي والهجري (أم القرى)، المدينة، الصلاة القادمة مع عدّ تنازلي، جدول اليوم، متابعة القراءة، ورد اليوم، أذكار اليوم، الحفظ والمراجعة، ملخص التقدم، اختصارات، وبطاقة الإهداء.
- **القرآن الكريم:** 114 سورة و6236 آية بالرسم العثماني (حفص عن عاصم)، فهارس السور والأجزاء والأحزاب والصفحات (604)، الانتقال لآية برقمها أو بمرجع مثل `2:255`، حفظ آخر موضع تلقائيًا، علامات مرجعية، ملاحظات شخصية، تكبير/تصغير الخط، وضع ليلي، وضع قراءة دون مشتتات، نسخ ومشاركة الآيات، علامات الصفحات والأجزاء ومواضع السجود، تسجيل القراءة.
- **البحث:** في السور والآيات والأذكار والأدعية والدروس، دون اعتبار للتشكيل واختلاف الهمزات والرسم العثماني، ودون تعديل النص المعروض.
- **الحفظ والمراجعة:** اختيار السورة والآيات، تقسيم إلى مقاطع، هدف يومي مرن، الاستماع مع تكرار الآية، إخفاء النص للاختبار أو إظهار أوائل الآيات، تقييم يدوي (لم أتذكر / بصعوبة / جيد / متقن)، جدولة مراجعة متباعدة (SM-2 مبسطة)، الحالات: جديد / قيد الحفظ / محفوظ / يحتاج إلى مراجعة، إيقاف واستئناف وحذف.
- **مواقيت الصلاة:** نحو 8000 مدينة حول العالم (مع البحث بالعربية والإنجليزية)، أو الموقع الحالي بإذن المستخدم، أو إدخال الإحداثيات يدويًا. 12 طريقة حساب، العصر الجمهور/الحنفي، قواعد خطوط العرض العليا، تعديل بالدقائق لكل صلاة لمطابقة التقويم المحلي، المنطقة الزمنية والتوقيت الصيفي لكل مدينة، جدول 7 أيام. مدن فلسطين (نابلس، القدس، غزة، الخليل، رام الله، جنين…) كل منها بإحداثياته.
- **التنبيهات:** لكل صلاة على حدة، مع تنبيه قبل الوقت، وتذكير بأذكار الصباح والمساء (انظر القيود أدناه).
- **القبلة:** زاوية القبلة محسوبة رياضيًا، المسافة إلى الكعبة، بوصلة حية عند توفر المستشعر، تعليمات المعايرة، ورسالة واضحة وبديل عند غياب المستشعر.
- **الأذكار:** الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، المنزل، الطعام واللباس، السفر، المسجد والوضوء والخلاء، ومتفرقة — مع التخريج، والتمييز بين القرآن والحديث، وعداد اختياري، وتسجيل الإتمام، والمفضلة، والبحث.
- **الأدعية:** قرآنية، من السنة الصحيحة، للوالدين والأموات، الرزق، الفرج والصبر، الكرب والحزن، الاستغفار والتوبة، الشفاء والرقية، السفر، وعامة.
- **الاستماع:** 12 قارئًا، تشغيل السورة كاملة أو من آية محددة، السابق/التالي، تكرار الآية أو السورة، السرعة، مستوى الصوت، متابعة آخر استماع، التحكم من أزرار النظام (Media Session)، وتنزيل السور للاستماع دون اتصال.
- **التفسير والتعلم:** التفسير الميسر، والمختصر، والسعدي، وابن كثير، والبغوي، والميسر في غريب القرآن (معاني المفردات) — يُحمَّل عند الطلب ويبقى محفوظًا. دروس: أركان الإسلام والإيمان، الوضوء، الصلاة، الغسل، التيمم، مع الأدلة.
- **ورد اليوم و«ابدأ رحلتك»:** ورد يومي بالصفحات مع متابعة الختمة، وبرامج مقترحة حسب الهدف والوقت، بلا لوم، مع إمكانية البدء من جديد دائمًا.
- **متابعة التقدم:** أيام القراءة، الآيات والصفحات، الحفظ، المراجعات، الأذكار، تقارير أسبوعية وشهرية — من سجل المستخدم الفعلي فقط.
- **الإعدادات:** المدينة، طريقة الحساب، التنبيهات، الخط، المظهر الفاتح/الداكن، اللغة، تصدير البيانات واستعادتها وحذفها، الخصوصية، مصادر المحتوى.
- **عن التطبيق ورسالة الوفاء:** نص الإهداء كاملًا كما هو، مع سطر إهداء هادئ أسفل الصفحات (يمكن إخفاؤه من الإعدادات، ولا يظهر داخل قارئ المصحف حتى لا يشغل عن القراءة).
- **العمل دون إنترنت:** الواجهة، والمصحف كاملًا، والأذكار والأدعية، والدروس، وبيانات المستخدم، وما سبق تحميله من تفسير وتلاوات.

### غير المكتملة أو المحدودة (بصراحة)

| الميزة | الحالة |
|---|---|
| تنبيهات والتطبيق مغلق | المتصفح لا يسمح بجدولة إشعارات موثوقة والتطبيق مغلق؛ تعمل التنبيهات ما دام التطبيق مفتوحًا (ولو في تبويب بالخلفية). الحل الكامل في نسخة الهاتف. |
| التلاوات | تُبث من خادم EveryAyah. **لم أستطع الوصول إلى هذا الخادم من بيئة البناء**، فاختُبر المشغل بملف صوتي محلي بديل. يُرجى التحقق عند أول تشغيل على جهازك؛ إن لم يعمل قارئ معين تظهر رسالة واضحة. |
| تنزيل التلاوات للعمل دون اتصال | منفَّذ، لكنه غير مختبر مع الخادم الحقيقي للسبب نفسه. |
| أسباب النزول | لم يُضمَّن مصدر معتمد قابل لإعادة الاستخدام؛ يظهر توضيح بدل محتوى غير موثق. |
| البحث في التفسير | غير متاح (التفسير يُحمَّل عند الطلب ولا يُضمَّن كاملًا). |
| الواجهة الإنجليزية | القوائم فقط (تمهيد). المحتوى بالعربية. |
| محتوى الأطفال | مخطط لإصدار لاحق. |
| الجداول الرسمية المحلية للمواقيت | لا يوجد استيراد لتقويم رسمي بعد؛ يمكن المطابقة يدويًا بتعديل الدقائق لكل صلاة. |
| تقييم النطق الآلي في الحفظ | غير منفذ عمدًا؛ التقييم يدوي. |
| المزامنة السحابية | غير مفعّلة؛ توجد طبقة جاهزة للتوسعة (`src/sync`)، والنسخ الاحتياطي اليدوي متاح. |
| المراجعة الشرعية | الأذكار والدروس مكتوبة بعناية مع التخريج، لكنها **تحتاج مراجعة متخصص شرعي قبل النشر العام**. |

## الاختبارات ونتائجها

نتائج آخر تشغيل (19 أكتوبر 2026):

- **الإصدار 0.2: 103 اختبار وحدات و32 اختبار متصفح — كلها ناجحة** (تفاصيل الإضافات في تقرير 0.2).
- **اختبارات الوحدات (Vitest) في 0.1: 80 اختبارًا — كلها ناجحة.** تشمل:
  - سلامة المصحف: 114 سورة، 6236 آية، تطابق عدد آيات كل سورة مع مرجع مستقل، عدم وجود فجوات أو تكرار في الترقيم، مطابقة النص حرفيًا للمصدر، بصمة SHA-256، وجود التشكيل، آيات مرجعية، بدايات الأجزاء والصفحات ومواضع السجود.
  - مواقيت الصلاة: مقارنة مكتبة adhan بتنفيذ مرجعي مستقل للمعادلات الفلكية لست مدن وخمسة تواريخ (الفرق أقل من دقيقتين ونصف)، العصر الحنفي، الطريقة المصرية، أم القرى، التعديل اليدوي، اختلاف مواقيت نابلس وغزة والخليل والقدس، والتوقيت الصيفي (نيويورك ولندن بدءًا وانتهاءً).
  - القبلة: قيم مرجعية منشورة (نيويورك، لندن، جاكرتا، القاهرة) ومطابقة مكتبة مستقلة.
  - التخزين: الحفظ والاسترجاع وإعادة الفتح، النسخ الاحتياطي والاستعادة، رفض الملفات غير الصالحة.
  - المحتوى: لكل ذكر مصدر، المراجع القرآنية صحيحة، درجة «صحيح» فقط لما في الصحيحين، **لا يوجد نص قرآني مكتوب يدويًا في الشيفرة**، نص الإهداء والاسم والكنية لم يتغيرا، لا مكتبات إعلانات أو تتبع.
- **اختبارات المتصفح (Playwright): 22 اختبارًا — كلها ناجحة.** تشمل: كل روابط التنقل، RTL، الإهداء، خلو التطبيق من الإعلانات، لوحة المفاتيح، فتح السور والانتقال لآية، حفظ الموضع والعلامات والملاحظات بعد إعادة التحميل، تسجيل القراءة، البحث، اختيار نابلس ثم غزة، القدس والخليل ضمن فلسطين، القبلة، الأذكار والعداد، المفضلة، الحفظ والتقييم، تشغيل الصوت والانتقال بين الآيات، رسالة خطأ الصوت، الوضع الليلي، تصدير النسخة الاحتياطية، **إعادة التشغيل دون إنترنت**، وشاشة الهاتف دون تمرير أفقي.
- خلال الاختبارات اكتُشف خطأ حقيقي (فشل حفظ ملاحظة جديدة في Chrome) وأُصلح.

التفاصيل في [docs/TESTING.md](docs/TESTING.md).

## بنية المشروع

```
islamic-companion/
├── public/
│   ├── data/quran/quran.json   # نص المصحف (مولَّد ومتحقق منه — لا يُعدَّل يدويًا)
│   ├── data/quran/meta.json    # السور والأجزاء والأحزاب والصفحات والسجدات + بصمة SHA-256
│   ├── data/cities.json        # المدن مع الإحداثيات والمنطقة الزمنية
│   └── icon*.{svg,png}
├── scripts/build-data.mjs      # يولّد ملفات البيانات من مصادرها ويتحقق من سلامتها
├── src/
│   ├── app/                    # التطبيق، المسارات، التخطيط العام
│   ├── features/               # صفحة لكل قسم (home, quran, memorize, prayer, qibla, adhkar, listen, learn, wird, progress, journey, search, settings, about)
│   ├── components/             # مكونات مشتركة (منتقي المدينة، بطاقة الذكر، المشغل العائم…)
│   ├── services/               # منطق العمل: القرآن، المواقيت، القبلة، المراجعة، الصوت، التفسير، الإحصائيات، الخطط
│   ├── content/                # المحتوى الديني الموثق (الأذكار، الأدعية، الدروس، الإهداء، القراء)
│   ├── db/                     # IndexedDB، المستودعات، النسخ الاحتياطي
│   ├── platform/               # قدرات الجهاز (الموقع، الإشعارات، البوصلة، المشاركة) — تُستبدل في الهاتف
│   ├── sync/                   # طبقة المزامنة المستقبلية (غير مفعّلة)
│   ├── state/                  # الإعدادات
│   ├── i18n/                   # نصوص الواجهة (عربي/إنجليزي)
│   └── styles/                 # الهوية البصرية
├── e2e/                        # اختبارات المتصفح
└── docs/                       # المتطلبات، المصادر والتراخيص، الافتراضات، التكاليف، الخصوصية، خطة الهاتف، الاختبارات
```

## خطة التطوير التالية (مختصر)

1. **مراجعة شرعية** للأذكار والدروس، والتحقق من شروط المصادر (QuranEnc، EveryAyah، كتب التفسير).
2. **Android** عبر Capacitor: إشعارات محلية مجدولة للصلاة، تشغيل صوت في الخلفية، تحديد الموقع، البوصلة، والبيانات كما هي.
